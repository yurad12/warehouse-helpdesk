# 파손 팔레트 처리 규정

## 격리
파손이 의심되는 팔레트는 일반 출고 구역에서 분리하여 HOLD 구역으로 이동해야 한다.

## 기록
작업자는 팔레트 ID와 파손 사유를 기록해야 한다.

## 출고
파손 여부가 확인되지 않은 팔레트는 출고 대상으로 처리하지 않는다.

## 담당자 확인
HOLD 구역으로 이동한 팔레트는 담당자가 육안 점검 또는 사진 증빙을 확인한 뒤 정상 출고, 보수, 폐기 중 하나로 후속 조치를 결정한다.

## HelpDesk 안내
AI HelpDesk는 파손 의심 팔레트에 대해 HOLD 구역 보관, Pallet ID 기록, 파손 사유 기록을 안내한다. 실제 재고 상태 변경은 담당자 확인 이후 운영 시스템에서 처리한다.
